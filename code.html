The story / Project Sentinel

Not every asteroid is a threat. But every observation tells a story.

A small experiment in finding meaningful patterns within thousands of historical near-Earth-object observations.

01 / THE QUESTION

Which objects deserve a closer look?

Astronomers monitor thousands of near-Earth objects because each observation can refine what is known. The question is not whether one measurement proves danger, but which records merit closer examination.

02 / THE EXPERIMENT

90,836 observations. Three measurements. One question.

Sentinel learns from historical observations using absolute magnitude, relative velocity, and miss distance. It looks for patterns associated with the dataset's historical hazardous label.

03 / THE LIMITATION

Finding patterns is not the same as predicting impact.

This three-feature classifier cannot calculate impact probability. Missing orbital parameters, including MOID, limit its use; its recall-oriented approach can also create false positives.

04 / THE FUTURE

A starting point, not a finished scientific instrument.

Richer orbital data, explainable AI, improved independent validation, and current measurements with explicit provenance could strengthen future versions.

Integration Methodology

Local integration boundary for the reviewed classifier. Its exact saved feature contract, units, threshold, and limitations are exposed by /api/model-info; no unverified evaluation metric is displayed.

Feature Extraction

The supplied development dataset currently includes name, absolute magnitude, estimated diameter range, relative velocity, miss distance, orbiting body, sentry flag, and a hazard label. Orbital-element features require a confirmed source.

Ensemble Classifier

The deployed artifact is a HistGradientBoostingClassifier with three saved input features. The metadata does not contain verified evaluation metrics or calibration evidence, so neither is claimed here. The output is a hazardous designation, not an impact forecast.

Uncertainty Quantification

This interface will display only backend-provided validation and result information. It does not estimate collision or impact probabilities and must not infer uncertainty without a verified model contract.
